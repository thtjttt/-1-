# ระบบติดตามเอกสารชุดเบิก

ระบบเล็ก ๆ ของสำนักพิมพ์อมตะ สำหรับติดตามเอกสารชุดเบิกแต่ละชุด ว่า

- ส่งออกแล้วหรือยัง และส่งวันไหน
- เลขพัสดุอะไร (กดเช็คกับไปรษณีย์ไทยได้)
- ถึงลูกค้าวันไหน และใครเป็นคนรับ

## หน้าในระบบ
- `index.html` — หน้าแรก
- `claims.html` — รายการชุดเบิก ค้นหาและกรองตามสถานะได้
- `add-claim.html` — เพิ่มชุดเบิกใหม่ (กำลังจัดทำ)

## วิธีเปิดดู
ดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดในเบราว์เซอร์

ข้อมูลเก็บไว้ในเบราว์เซอร์ของเครื่องที่เปิด และข้อมูลตัวอย่างทั้งหมดเป็นข้อมูลสมมติ
